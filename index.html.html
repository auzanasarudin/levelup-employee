Pertanyaan yang sering muncul

Apakah perlu internet?
Tidak. Aplikasi berupa file yang dibuka di browser dan berjalan offline, di laptop maupun HP.
Data saya disimpan di mana?
Di penyimpanan browser perangkatmu sendiri, tidak dikirim ke server. Ada fitur backup dan restore agar data bisa dipindah.
Kenapa data demo direset setiap 10 menit?
Demo dipakai banyak orang untuk mencoba, jadi datanya sementara. Versi penuh menyimpan datamu permanen dan tidak pernah direset.
Bisa beli satuan, tidak harus paket?
Bisa untuk item yang sudah dibuka. Item yang belum tersedia satuan ditandai Segera hadir. Paket selalu lebih hemat daripada membeli isinya satu per satu.
Bagaimana saya menerima produk setelah membayar?
Ikuti instruksi di halaman checkout. Jika ada kendala, hubungi admin lewat WhatsApp.
